# 데일리자격증 — 보내기 버튼

[데일리자격증](https://github.com/reepower84-png/daily-cert)을 **보낼지 말지 결정하는 한 장짜리 페이지**입니다.

매일 아침 8시쯤 디스코드로 "오늘 데일리자격증을 보낼까요?" 알림이 오면,
그 링크로 들어와 버튼을 누를 때만 자격증 목록이 나갑니다. 누르지 않으면 아무 일도 일어나지 않습니다.

- **오늘 뉴스에서 가장 많이 나온 주제**를 먼저 보여 줍니다. 근거가 된 기사 제목도 같이 나옵니다.
- **주제를 바꿀 수 있습니다.** `자동` 이면 누르는 그 시각의 뉴스로 다시 고릅니다 —
  아침에 묻고 저녁에 누르는 날이 있어서, 아침에 고른 주제를 그대로 쓰지 않습니다.
- **전에 보낸 주제도 다시 이슈가 되면 옵니다.** 추석 앞이면 '전통'이, 수능 철이면
  '진로'가 다시 뜨니까요. 대신 `↩ 9월 22일에 보내드린 주제입니다` 처럼 **언제 보냈는지**를
  달아 구분하고, 자격증도 처음 보는 것은 `신규`, 전에 보낸 것은 날짜를 붙입니다.
- **같은 주제가 또 와도 자격증은 새것부터.** 아직 안 보여드린 자격을 앞에 세우므로,
  두 번째 카드에는 다른 여섯 개가 실립니다.

- 주소: <https://reepower84-png.github.io/daily-cert-app/>
- 이 저장소는 공개지만 **비밀은 하나도 없습니다.** 주제어 사전·진도·웹후크는 모두
  비공개 저장소 `daily-cert` 에 있고, 이 페이지는 브라우저에 저장된 개인 토큰으로
  그 저장소의 발송 워크플로를 실행시키고 진도를 읽을 뿐입니다.
- 토큰은 이 기기의 `localStorage` 에만 있습니다. 서버로 보내지 않습니다.

## 처음 설정

**데일리북·데일리영어 앱을 쓰고 있다면 새로 발급하지 않아도 됩니다.** 그 토큰은 권한 모양이
여기와 똑같습니다 (Actions = Read and write, Contents = Read-only). [가진 토큰](https://github.com/settings/personal-access-tokens)의
Repository access 에 `daily-cert` 만 더하고 이 페이지를 새로고침하면 됩니다 —
버튼 앱들이 같은 주소에 얹혀 있어 브라우저 저장소를 공유하므로, 이 페이지가 형제 앱의
토큰을 알아서 집어 씁니다. 파인그레인드 PAT 은 저장소 목록을 고쳐도 문자열이 바뀌지 않고,
그 문자열은 발급할 때 한 번만 보여 줘서 손으로 옮겨 적을 수도 없습니다.

새로 만들려면:

1. 페이지를 열면 토큰을 물어봅니다.
2. [Fine-grained PAT 발급](https://github.com/settings/personal-access-tokens/new)
   - Repository access: **Only select repositories** → `daily-cert`
   - Permissions: **Actions** = Read and write, **Contents** = Read-only
3. 붙여넣고 저장하면 끝. 이후로는 링크만 열면 됩니다.
4. (선택) 브라우저 메뉴 → '홈 화면에 추가' 하면 앱처럼 쓸 수 있습니다.
